# Safe examples

These examples contain no Bluetooth device identities, actual messages, active
schedules, credentials, or production settings. Device and schedule lists are
empty. The design example contains only a generic WELCOME message.

No example is activated automatically. The application tolerates missing local
device files and can discover devices only when a user explicitly chooses Scan.
For a separate test installation, copy an example to the corresponding root
filename if needed. Keep any discovered identities, schedules, uploaded media,
history and settings local; they are intentionally covered by .gitignore.
